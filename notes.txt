WHY THE CURRENT RESULT STILL DOES NOT MATCH THE MOCKUPS
======================================================================

The current work mostly restyles and filters the existing application.

Current structural approach:

- one existing sidebar;
- a mode selector that hides or shows old sidebar sections;
- floating selected-station popup;
- recursive widget-tree dialog styling;
- decorative station-diamond overlays after redraw.

Mockup structural approach:

- clear top application bar;
- dedicated left mode rail;
- mode-specific secondary panel;
- map as the center workspace;
- persistent right docked inspector;
- explicit component hierarchy;
- explicit dialog layouts;
- selection details outside the map.

The largest remaining gap is structural, not color selection.

Do not spend another run adjusting popup padding, title width, or badge size
before implementing the workspace shell and docked inspector.
