Current World Map Process
-------------------------
1. in the app, click Auto Fill Step to load the next Blackport box batch and render it in one task
2. repeat Auto Fill Step until the requested rectangle is covered
3. optionally run `python3 -m worldgen status` to see the current cache and expected world path
4. for backend debugging only, run `python3 -m worldgen load-chunks` then `python3 -m worldgen render`
5. if render says LevelDB repair is needed, run `python3 -m worldgen repair-db` to write a backup and repaired inspection copy
6. run `python3 -m worldgen stop` if the server was intentionally left running
