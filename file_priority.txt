PLUMVILLE FILE PRIORITY LIST

PURPOSE

This file tells Codex which files should receive attention first.

Priority considers:

- active checklist leverage;
- regression risk;
- ability to test locally;
- architectural ownership;
- whether a change requires a public phone push.

Update this file after every implementation run.

Do not lower a file merely because code was written. Lower it after the
relevant behavior is tested and stable.
